# OnlineBookStore

**Project Overview**

This project demonstrates the design and analysis of an **Online Book Store** database using **PostgreSQL**.

The objective is to simulate a real-world online bookstore by creating a relational database, importing datasets, and answering business questions using SQL.

Through this project, I practiced writing SQL queries to analyze customer behavior, sales performance, inventory, and revenue.


**** Objectives****

- Design a relational database
- Create tables with Primary and Foreign Keys
- Import data from CSV files
- Perform data analysis using SQL
- Generate business insights from transactional data
